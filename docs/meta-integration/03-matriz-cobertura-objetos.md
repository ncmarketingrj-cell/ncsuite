# 03 — Matriz de Cobertura de Objetos, Níveis, Fluxos e Telas

| Domínio / Objeto Meta | Origem Graph API v21.0 | Edge Function / Serviço | Tabela(s) / View Supabase | Telas / Rotas Consumidoras | Paridade & Invariantes Garantidos |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Contas de Anúncios | `/me/adaccounts` (paginado, múltiplos tokens) | `sync-meta-ads` | `ad_accounts`, `sync_history` | Todas as telas Ads | Só limpa contas órfãs quando todas as listagens de token fecham sem falha nem truncamento; `last_sync` atualiza apenas após sucesso da conta |
| Alcance Deduplicado da Conta | `/{act}/insights` (`level=account`, diário + período) | `sync-meta-ads` | `meta_account_daily_stats`, `meta_account_period_stats`, `daily_metrics` | `/dashboard`, `/metricas`, `/relatorios`, `/clientes/:id`, `run-automations` | Conta com alcance real deduplicado separado de `SUM(campaign.reach)` |
| Campanhas & Métricas | `/{act}/campaigns` + `/{act}/insights?level=campaign` | `sync-meta-ads` | `campaigns`, `metrics`, `meta_period_stats` | `/metricas`, `/dashboard`, `/cockpit`, `/auditoria`, `/relatorios`, `/simulador`, `victoria-agent` | Sem filtro oculto obrigatório para sem-entrega (toggle `Sem entrega (N)`); preservação do objetivo bruto; zero coerção de `UNKNOWN` ou `OUTCOME_ENGAGEMENT` |
| Conjuntos de Anúncios (`adset`) | `/{act}/adsets` + `/{act}/insights?level=adset` | `sync-meta-ads` | `ad_sets`, `asset_metrics`, `meta_period_stats` | `/metricas` (aba Conjuntos), `/relatorios`, `victoria-agent` | Aba Conjuntos carrega todos os conjuntos da conta mesmo sem checkbox prévio de campanha; guarda `optimization_goal`, `destination_type`, `attribution_spec` |
| Anúncios (`ad`) & Criativos | `/{act}/ads` + `/{act}/insights?level=ad` | `sync-meta-ads` | `ads`, `asset_metrics`, `meta_period_stats` | `/metricas` (aba Anúncios), `/relatorios`, `/cockpit`, `/criativos` | Paginação >1.000 linhas no PostgREST e Graph API; preserva valor nativo de campanha e expõe divergência campanha vs soma dos anúncios em metadado (`adResultsSum`) |
| Breakdowns (Idade, Gênero, Região, Dispositivo, Hora, Posicionamento) | `/{act}/insights` com `breakdowns=...` | `sync-meta-ads` | `demographic_metrics`, `placement_metrics`, `hourly_metrics`, `region_metrics`, `device_metrics` | `/metricas` (tab Demográficos & Posicionamentos) | Sem simulador aleatório: quando vazio na API, exibe estado explícito `hasRealData = false` |
| Faturamento / Billing | `/me/adaccounts`, `/{act}/transactions` | `get-meta-billing` | `billing_snapshots`, `billing_transactions` | `/cobrancas` | Diferencia `spend_cap = 0` (`no_cap` = "Sem limite definido") de permissão ausente (`unavailable` = "Indisponível por permissão"); exibe status e `disable_reason` |
| Social Orgânico & Planejamento | `/me/accounts`, `/{page}/posts`, `/{page}/scheduled_posts`, `/{page}/promotable_posts`, `/{ig}/media`, `/{ig}/stories`, `/*/insights` | `sync-social-media`, `src/lib/metaSocialService.ts` | `social_pages`, `social_posts`, `social_daily_metrics` | `/social`, `/social-insights`, `/social-audit` | Zero alcance/impressão aleatório; retém crosspost dual-channel (FB + IG); mostra amostra real do heatmap e limitação nativa de agendamento IG |
| Relatórios & Snapshots | DB consolidado + `reportTemplateEngine` | `src/lib/reportTemplateEngine.ts` | `metrics`, `meta_account_period_stats` | `/relatorios` | Arredondamento único (`formatCurrencyBRLStrict` / `roundCurrency`); sem valores default fictícios (`25.538,08` / `244`); distingue `Alcance (Conta)` vs `Alcance (Soma)` |
| Automações, Heartbeat & IA | DB consolidado | `run-automations`, `agent-heartbeat`, `victoria-agent` | `metrics`, `meta_account_daily_stats`, `automation_alerts` | Notificações / Victoria Chat / WhatsApp | ROAS calculado apenas com receita real (`null` quando ausente); corrigido `ZERO_DELIVERY` crash; zero overrides por nome/data fixa |
